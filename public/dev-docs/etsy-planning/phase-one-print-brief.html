What this is for

Read this first — it changes how you'd approach the job.

We're opening our own Etsy shop selling personalised wedding and celebration signage — the same products we currently print and dispatch on behalf of other Etsy sellers. This batch exists so we can photograph a complete, consistent set of listing images.

That means two things. Everything in one design family must look like it belongs to the same family — same typeface, same weight, same margins. And every piece must be photographable: clean edges, no handling marks, no dust.

Where a physical print isn't sensible — an A0 board printed purely to be photographed once — a composite or AI mockup is fine. See Photography for where each is appropriate.

Seating plan

The seating plan must show a realistic guest count. Ten tables of eight — eighty names. Competitor listings all show full plans, and a mockup with four names on it looks like a placeholder and undersells the product. This is the single most important detail in this brief.

MM family — tables numbered: Table One … Table Ten EU family — tables named: Willow · Hazel · Rosemary · Juniper · Bramble Clover · Heather · Fennel · Laurel · Sorrel Eight guest names per table. Use plausible UK full names, mixed lengths — some short, some long enough to test the longest line the layout has to handle.

Where mockups are and aren't acceptable

Composites and AI mockups are fine for in-situ styling, size variants, and colourway alternatives — there's no sense printing an A0 board to photograph it once.

They are not acceptable for edge and texture detail, where the whole point is showing real material. And the design shown must always be the design the customer receives — a mockup that flatters beyond what we can print is a returns problem and an Etsy policy problem.

Appendix — guest names

Eighty names for the two seating plans. Use the same list on both boards — it is one fictional wedding shown in two design families, so the guest list should match.

The mix is deliberate: it reflects the UK as it is now, and it deliberately varies name length. Alexandra Kingsley-Moore and Amelia Fitzgerald-Barnes are the longest lines the layout has to cope with; Joe Marsh and Beth Rowe are the shortest. If the design holds both without looking uneven, it will hold a real customer’s list.
